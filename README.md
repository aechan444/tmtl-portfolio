# Technology in Mathematics Teaching and Learning: Portfolio

Group 4 · BSED-Math 2A Newton · Cebu Technological University, Argao Campus
Course: Technology for Teaching and Learning in Mathematics (TTL 1)

A web portfolio of our outputs for the course:

- **Short Introduction**: “How can technology support mathematical thinking?”
- **Module 2**: TTL Concept Map
- **Module 3**: Learning Experience Analysis & Redesign (“Fraction–Decimal Match and Explain”) and a role play on misleading digital media graphs
- **Module 4**: Field Study, an interview analysis with an in-service mathematics teacher using TPACK and SAMR
- **Reflection**

## Viewing

Open `index.html` in a browser, or visit the GitHub Pages site for this repository. PDFs open in a built-in viewer, and the TMTL Helper chatbot (bottom-left) answers questions about the portfolio.
